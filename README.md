🖼️ Image to Text Converter<br><br>
A simple Android application that lets you extract text from images using OCR (Optical Character Recognition). Built with Android Studio and powered by ML Kit / Tesseract (whichever you used — you can update this).
***
🚀 Features<br>
- 📷 Select images from the gallery

- 🔍 Extract text using OCR

- 📝 Copy or share the extracted text

- 🌙 Light & Dark mode support
